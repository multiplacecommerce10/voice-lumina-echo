# Salvar o código no GitHub

O código passa a ficar guardado na sua conta do GitHub, com histórico completo de todas as alterações e sincronização automática nos dois sentidos.

## O que você faz (leva ~2 minutos)

1. No canto inferior esquerdo do chat, abra o menu **+** (Plus).
2. Escolha **GitHub > Connect project**.
3. Autorize o aplicativo Lovable no GitHub.
4. Escolha a conta ou organização onde o repositório será criado.
5. Clique em **Create Repository**.

Só você pode fazer esses passos — é uma autorização pessoal da sua conta GitHub, que eu não consigo executar por aqui.

## O que acontece depois

- Todo o projeto (páginas, e-mails, lógica de pagamento, scripts de teste) vai para o repositório.
- Cada alteração feita aqui é enviada automaticamente para o GitHub.
- Alterações feitas no GitHub voltam automaticamente para cá.
- Você pode baixar o código a qualquer momento em **Code > Download ZIP**.

## Pontos importantes

- Senhas e chaves (Stripe, Taskade, e-mail) **não** vão para o repositório: ficam guardadas separadamente, em segurança.
- Os dados do banco (matrículas, leads) não ficam no GitHub. Eles são exportados à parte, em Cloud > Advanced settings > Export data.
- Nada do site, dos e-mails ou da automação muda ao conectar — é apenas cópia e histórico.

## Depois de conectar

Me avise quando estiver feito e eu confirmo que o repositório recebeu o projeto completo e que nenhum arquivo essencial ficou de fora.
